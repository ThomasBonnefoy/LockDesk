Télécharger LockDesk

Version bêta, pour Windows 11. Aucun compte à créer.

Les fichiers

  • Installateur (x64 et ARM64)

    Un seul installateur pour tous les PC Windows 11. Il demande les droits administrateur (voir plus bas).

  • Zip pour Intel / AMD (x64)

Installer

Avec l'installateur

  1. Lancez LockDesk-Setup-vX.Y.Z.exe et acceptez la demande de droits administrateur.
  2. Suivez l'assistant. LockDesk apparaît dans le menu Démarrer.

L'installateur ajoute aussi, pour tous les utilisateurs du PC, un petit certificat créé sur votre PC. Il sert uniquement à afficher la page « Site bloqué » quand vous ouvrez un site sécurisé (https) que vous avez bloqué. Sans lui, le navigateur affiche sa propre page d'erreur, et tout le reste fonctionne pareil. La désinstallation le retire. Si vous ne voulez pas de ce certificat, prenez le zip.

Avec le zip

  1. Téléchargez le zip qui correspond à votre processeur, puis décompressez-le (clic droit, Extraire tout).
  2. Il contient un seul fichier, LockDesk.exe. Lancez-le : rien à installer, aucun droit administrateur, tout ce dont il a besoin est inclus.

Premiers pas

  1. Page Applications : ajoutez les programmes à mettre de côté pendant le mode. Page Sites web : les sites à bloquer.
  2. Page Fond d'écran : choisissez une image, ou gardez le fond uni.
  3. Page Mode : cliquez sur Activer le mode concentration, ou appuyez sur Ctrl + Alt + F. Le même bouton, ou le même raccourci, arrête le mode.

« Windows a protégé votre ordinateur »

Au premier lancement, Windows peut afficher cet avertissement (SmartScreen) : l'application n'est pas encore signée numériquement, et il se méfie des programmes qu'il voit encore peu souvent. Cliquez sur Informations complémentaires, puis sur Exécuter quand même.

Configuration requise

  • Windows 11, avec un processeur Intel ou AMD (x64) ou ARM (ARM64). Windows 10 n'est pas pris en charge.
  • Aucune connexion à Internet n'est nécessaire.

Désinstaller

Si vous avez coché « Lancer au démarrage de Windows », décochez-le d'abord (page Options), puis quittez l'application (menu de son icône près de l'horloge, Quitter).

  • Installateur : Paramètres de Windows, Applications, LockDesk, Désinstaller.
  • Zip : supprimez LockDesk.exe.

Pour effacer aussi vos réglages et vos statistiques, supprimez le dossier %LOCALAPPDATA%\ConcentrationWindows.
