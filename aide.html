Questions fréquentes

Faut-il créer un compte ?

Non. L'application n'a besoin d'aucun compte et ne se connecte à Internet pour rien. Vos modes, vos réglages et vos statistiques restent sur votre PC.

Mon fond d'écran et mes fenêtres reviennent-ils vraiment comme avant ?

Oui. Avant le moindre changement, l'application enregistre l'état d'origine de votre PC. Elle le remet en place à la fin du mode, avant l'arrêt de Windows si vous éteignez pendant un mode, et au démarrage suivant après une coupure de courant ou un plantage.

Est-ce que les applications fermées perdent mon travail ?

Non. Une application de votre liste est soit réduite, soit fermée poliment, comme si vous cliquiez sur sa croix : elle peut vous proposer d'enregistrer. Rien n'est jamais fermé de force.

Le blocage des sites marche-t-il dans tous les navigateurs ?

Il marche dans les navigateurs qui suivent les réglages réseau de Windows, sans extension. Il a été vérifié avec Chrome et Opera GX ; Firefox et Edge n'ont pas encore été essayés. Si un proxy est déjà configuré sur votre PC (en entreprise, à l'école, avec un VPN), l'application n'y touche pas et vous le signale : le blocage ne fait alors rien.

Un site bloqué affiche une erreur du navigateur, pas « Site bloqué »

Sur un site sécurisé (https, c'est presque tous), le navigateur affiche sa propre page d'erreur. La page « Site bloqué » de LockDesk ne s'affiche que si vous avez installé l'application avec l'installateur, qui ajoute pour cela un certificat local. Le site reste bloqué dans les deux cas.

Faut-il des droits administrateur ?

Pas pour le zip : l'application fonctionne avec un compte Windows ordinaire. L'installateur, lui, demande les droits administrateur pour s'installer dans « Program Files » et pour ajouter le certificat local décrit ci-dessus.

Quelles versions de Windows sont prises en charge ?

Windows 11 seulement, avec un processeur Intel ou AMD (x64) ou ARM (ARM64). Windows 10 n'est pas pris en charge. La version ARM64 n'a été essayée que dans une machine virtuelle pour l'instant.

L'application lit-elle ce que je fais ?

Non. Elle regarde seulement quelles fenêtres sont ouvertes, pour mettre de côté celles de votre liste. Rien n'est envoyé : elle n'a aucune connexion à Internet (voir la politique de confidentialité).

Windows affiche « Windows a protégé votre ordinateur »

C'est l'avertissement SmartScreen : l'application n'est pas encore signée numériquement et Windows se méfie des programmes qu'il voit encore peu souvent. Cliquez sur Informations complémentaires, puis sur Exécuter quand même.

Quelque chose ne s'est pas passé comme prévu : que faire ?

C'est une version bêta, vos retours comptent. Écrivez-moi (adresse plus bas) en disant la version de LockDesk, ce que vous faisiez et ce qui s'est passé. Si votre bureau n'est pas revenu comme avant, le fichier session-end.log du dossier %LOCALAPPDATA%\ConcentrationWindows aide beaucoup : joignez-le.
